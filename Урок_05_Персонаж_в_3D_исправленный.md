# Unity — урок №5. Персонаж в 3D: движение и первый прыжок

> **Адаптированная методичка** по исходному уроку №5 «Персонаж в 3D». Сохраняем `CharacterController`, `GetComponent`, `Update`, ввод с клавиатуры, проверку земли, гравитацию и прыжок. Исправляем управление: **WASD зависит от камеры**, а персонаж плавно поворачивается в сторону движения, а не крутится вместе с мышью.

**Рекомендуемое время:** 80–90 минут.  
**После урока:** персонаж стоит на острове, ходит, поворачивается к направлению движения, прыгает по пробелу; камера из урока №4 следует за ним (пока без вращения мышью).

## 2. Подготовка модели персонажа

1. Откройте сцену `Level01` из урока №4.
2. Перетащите модель из `Assets/Characters` на большую стартовую площадку.
3. В Hierarchy назовите объект, например, **`character-digger`** — как на нашем работающем проекте.
4. Убедитесь, что модель находится **над** коллайдером земли и не утоплена в плитку.
5. Прикрепите компонент **Add Component → Character Controller** к объекту, который будет двигаться.

### Настройте капсулу Character Controller

Капсула должна охватывать тело модели, а нижняя часть — достигать подошвы. Для персонажа высотой примерно 2 Unity units можно **начать** с:

| Параметр | Пример |
|---|---|
| Height | 2 |
| Radius | 0.35 |
| Center | `(0, 1, 0)` |
| Step Offset | 0.3 |

Это **только начальный пример**, потому что размеры импортированных моделей различаются. Уменьшите или увеличьте коллайдер под реальный размер героя. Если pivot модели находится в центре, а не у ног, значения `Center` будут другими.

**Важный момент:** для этого способа передвижения персонажу не нужен `Rigidbody` — движение и столкновения контролирует `CharacterController`. Убедитесь, что нет другого скрипта, который также передвигает героя.

## 3. Настройка управления в Unity 6

В этой серии уроков используем знакомые команды `Input.GetAxisRaw` и `Input.GetButtonDown`, то есть **старый Input Manager**. Это сделано намеренно, чтобы не вводить новую систему Input Actions посреди темы.

Откройте **Edit → Project Settings → Player → Other Settings → Active Input Handling** и выберите **Both** или **Input Manager (Old)**. Если Unity попросит перезапустить редактор, согласитесь. В настройках Input Manager должны существовать стандартные оси `Horizontal`, `Vertical` и кнопка `Jump` (по умолчанию пробел).

Если оставить только `Input System Package (New)`, код с `UnityEngine.Input` может выдавать `InvalidOperationException`.

Документация Unity: https://docs.unity.cn/6000.6/Documentation/Manual/UIE-Runtime-Event-System.html

## 4. Создаём PlayerController.cs

В `Assets/Scripts` создайте **MonoBehaviour Script → PlayerController**. Прикрепите его к **тому же GameObject**, на котором находится `CharacterController`.

### Ключевые части, которые разбираем у доски

```csharp
private CharacterController controller;

void Start()
{
    controller = GetComponent<CharacterController>();
}
```

Метод `GetComponent<CharacterController>()` получает уже добавленный компонент. `Start()` выполняется в начале игры.

```csharp
float moveX = Input.GetAxisRaw("Horizontal");
float moveZ = Input.GetAxisRaw("Vertical");
Vector3 inputDirection = new Vector3(moveX, 0f, moveZ);
inputDirection = Vector3.ClampMagnitude(inputDirection, 1f);
```

`Horizontal` соответствует A/D, `Vertical` — W/S. Нормализация через `ClampMagnitude` не даёт ускоряться при движении по диагонали.

```csharp
Vector3 forward = cameraTransform.forward;
Vector3 right = cameraTransform.right;
forward.y = 0f;
right.y = 0f;
forward.Normalize();
right.Normalize();
```

Эти строки превращают направление камеры в **горизонтальное** направление: вверх и вниз персонаж перемещается только прыжком/гравитацией. Поэтому W означает «вперёд относительно камеры», а не всегда вдоль мировой оси Z.

```csharp
if (isGrounded && verticalVelocity < 0f)
{
    verticalVelocity = -2f;
}
```

`isGrounded` сообщает, стоит ли капсула на земле после предыдущего перемещения. Небольшая отрицательная скорость помогает сохранять контакт с землёй.

```csharp
if (Input.GetButtonDown("Jump") && isGrounded)
{
    verticalVelocity = Mathf.Sqrt(jumpHeight * -2f * gravity);
}

verticalVelocity += gravity * Time.deltaTime;
```

Начальная скорость направлена вверх. Гравитация (`gravity < 0`) на каждом кадре постепенно снижает её, а затем ускоряет падение. Объект не прыгает сам по себе: `CharacterController.Move()` **не применяет гравитацию автоматически**.

### Полный рабочий PlayerController.cs — версия урока №5

> Вставляйте **весь файл целиком**, а не фрагменты с многоточиями из исходной методички.

```csharp
using UnityEngine;

[RequireComponent(typeof(CharacterController))]
public class PlayerController : MonoBehaviour
{
    [Header("Movement")]
    public float speed = 5f;
    public float rotationSpeed = 12f;

    [Header("Jump")]
    public float jumpHeight = 2f;
    public float gravity = -9.81f;

    [Header("Camera")]
    public Transform cameraTransform;

    private CharacterController controller;
    private float verticalVelocity;

    void Start()
    {
        controller = GetComponent<CharacterController>();

        if (cameraTransform == null && UnityEngine.Camera.main != null)
        {
            cameraTransform = UnityEngine.Camera.main.transform;
        }
    }

    void Update()
    {
        bool isGrounded = controller.isGrounded;

        if (isGrounded && verticalVelocity < 0f)
        {
            verticalVelocity = -2f;
        }

        float moveX = Input.GetAxisRaw("Horizontal");
        float moveZ = Input.GetAxisRaw("Vertical");

        Vector3 inputDirection = new Vector3(moveX, 0f, moveZ);
        inputDirection = Vector3.ClampMagnitude(inputDirection, 1f);

        Vector3 moveDirection = inputDirection;

        if (cameraTransform != null)
        {
            Vector3 forward = cameraTransform.forward;
            Vector3 right = cameraTransform.right;

            forward.y = 0f;
            right.y = 0f;
            forward.Normalize();
            right.Normalize();

            moveDirection = forward * inputDirection.z
                + right * inputDirection.x;
            moveDirection = Vector3.ClampMagnitude(moveDirection, 1f);
        }

        if (moveDirection.sqrMagnitude > 0.01f)
        {
            Quaternion desiredRotation =
                Quaternion.LookRotation(moveDirection);

            transform.rotation = Quaternion.Slerp(
                transform.rotation,
                desiredRotation,
                Mathf.Clamp01(rotationSpeed * Time.deltaTime)
            );
        }

        if (Input.GetButtonDown("Jump") && isGrounded)
        {
            verticalVelocity = Mathf.Sqrt(
                jumpHeight * -2f * gravity
            );
        }

        verticalVelocity += gravity * Time.deltaTime;

        Vector3 fullMovement =
            moveDirection * speed + Vector3.up * verticalVelocity;

        controller.Move(fullMovement * Time.deltaTime);
    }
}
```

### Что здесь важно

- `speed` — скорость передвижения в метрах/секунду условного масштаба проекта.
- `rotationSpeed` — скорость плавного разворота героя.
- `cameraTransform` — направление камеры, относительно которого работают клавиши.
- `Quaternion.LookRotation(...)` задаёт направление, куда смотрит герой.
- `Quaternion.Slerp(...)` плавно разворачивает его вместо мгновенного поворота.
- `controller.Move(fullMovement * Time.deltaTime)` совершает одно перемещение за кадр и учитывает столкновения с землёй.

## 5. Связываем игрока и камеру

1. Выделите **Main Camera**. В компоненте `CameraFollow` перетащите `character-digger` в поле **Target**.
2. Выделите **character-digger**. В компоненте `PlayerController` перетащите **Main Camera** в поле **Camera Transform**.
3. Убедитесь, что Main Camera имеет **Tag = MainCamera** (если забыли установить Camera Transform, скрипт попробует найти её автоматически).
4. Убедитесь, что на Main Camera есть только **один** `CameraFollow`, а на игроке только **один** `PlayerController`.
5. Установите `Speed = 5`, `Rotation Speed = 12`, `Jump Height = 2`, `Gravity = -9.81`.
6. Нажмите Play и щёлкните внутри вкладки **Game**, чтобы клавиатурный ввод попадал в игру.

### Ожидаемое поведение

| Действие | Результат |
|---|---|
| W/S | Идти вперёд/назад относительно камеры |
| A/D | Идти влево/вправо относительно камеры |
| W + D | Движение по диагонали без дополнительного ускорения |
| Space | Один прыжок, если герой стоит на земле |
| Отпустить клавиши | Герой перестаёт двигаться |
| Перейти к другой платформе | Камера следует за игроком |

**Примечание:** на этом занятии мышь ещё не вращает камеру. Это будет основная тема занятия №6, где мы заменим простой `CameraFollow` на полноценную третьеличную камеру.

## 6. Типичные ошибки и решения

| Ошибка | Что проверить |
|---|---|
| Герой проваливается | На платформе есть `Box Collider`/`Mesh Collider`, `Is Trigger` отключён, капсула не ниже уровня земли |
| Прыжок не работает | `CharacterController.isGrounded`, размер капсулы, кнопка `Jump` и отсутствие стартового зависания над плиткой |
| WASD ничего не делает | Активен Input Manager или Both; вкладка Game в фокусе; нет ошибок Console |
| Камера показывает небо/землю | `CameraFollow.Target` назначен **корневому объекту игрока**, не отдельной детали модели |
| Герой смотрит боком | Внутри модели направление «вперёд» может отличаться от оси +Z. Разверните **визуальную модель как дочерний объект**, не ломая корневой объект управления |
