# Unity 6. Практическая работа: сбор монет и счётчик монет

**Продолжение занятия «Собираемые предметы, враги и здоровье»**  
**Уровень:** начинающие  
**Результат:** игрок собирает монеты, монеты исчезают, а число собранных монет отображается на экране и увеличивается автоматически.

> Мы **не меняем** готовые `CameraFollow.cs`, `PlayerController.cs`, `EnemyAI.cs`, `EnemyAttack.cs`, `PlayerEnemyCollision.cs`, `PlayerHealth.cs` и `Collectible.cs` (сердечки). Для монет создадим отдельные скрипты. Так студенты увидят, как добавлять новые механики, не ломая уже работающие.

## Что потребуется до начала

- Сцена с игроком, который ходит с помощью `CharacterController`.
- У корневого объекта игрока (`character-digger`) установлен **Tag = Player**.
- Работает сбор сердечек и система здоровья из предыдущего занятия.
- В проекте установлен **TextMeshPro** (обычно доступен в Unity по умолчанию).

**План занятия:**

1. Создаём монетку в сцене.
2. Пишем первый скрипт: исчезновение монетки.
3. Добавляем хранение количества монет у игрока.
4. Связываем монетку со счётчиком.
5. Создаём надпись «Монеты: 0» на экране.
6. Обновляем надпись автоматически.
7. Проверяем работу и выполняем самостоятельные задания.

---

## Этап 1. Создание монеты

**Задача:** создать объект, который будет отличаться от сердечка и сможет реагировать на вход игрока в область коллайдера.

### Пошагово в Unity

1. В окне **Hierarchy** выберите **GameObject → 3D Object → Cylinder**.
2. Назовите созданный объект **Coin**.
3. В `Transform` установите приблизительные размеры: `Scale X = 0.5`, `Y = 0.08`, `Z = 0.5`.
4. Поверните монету так, чтобы она выглядела как стоящая вертикально: например, `Rotation X = 90` (при необходимости подстройте под свою сцену).
5. Разместите объект немного выше поверхности, чтобы игрок мог к нему подойти.
6. Создайте материал золотистого цвета и назначьте его монете (необязательно).
7. У объекта уже есть `Capsule Collider` (для цилиндра Unity часто добавляет его автоматически). Для учебного примера удобнее **удалить его и добавить `Box Collider`**.
8. В `Box Collider` поставьте галочку **Is Trigger**. При необходимости нажмите **Edit Collider** и подгоните размеры области под монету.
9. Перетащите `Coin` из Hierarchy в папку `Assets/Prefabs`, если хотите создать несколько одинаковых монет (необязательно).

**Объяснение:** `Is Trigger` позволяет обнаружить пересечение с игроком, не создавая твёрдую стену. Для нашего игрока с `CharacterController` такой триггер подходит.

**Проверка:** монета видна в сцене, её коллайдер охватывает монетку и включён `Is Trigger`.

## Этап 2. Первая версия Coin.cs: предмет исчезает

**Задача:** повторить знакомый механизм собираемого предмета. Пока **без счётчика**.

1. В `Assets/Scripts` создайте C#-скрипт **Coin.cs**.
2. Откройте файл и вставьте код:

```csharp
using UnityEngine;

public class Coin : MonoBehaviour
{
    private void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player"))
        {
            Debug.Log("Монета собрана!");
            Destroy(gameObject);
        }
    }
}
```

3. Перетащите скрипт `Coin` на объект монеты.
4. Запустите игру и подойдите к монете.

**Объяснение кода:**

- `OnTriggerEnter(Collider other)` вызывается при входе другого коллайдера в триггер.
- `CompareTag("Player")` проверяет, что подошёл именно игрок.
- `Debug.Log(...)` выводит сообщение в консоль Unity.
- `Destroy(gameObject)` удаляет **монету**, потому что скрипт висит на монете.

**Проверка:** монетка исчезла и в Console появилось сообщение `Монета собрана!`.

**Вопрос студентам:** почему нельзя просто написать `Destroy(other.gameObject)`? (Потому что `other` — это объект, вошедший в триггер, то есть игрок.)

## Этап 3. Создаём CoinCounter.cs: храним количество монет

**Задача:** хранить число монет **на игроке**, а не отдельно в каждой монете.

1. Создайте скрипт **CoinCounter.cs**.
2. Вставьте **первую версию** кода:

```csharp
using UnityEngine;

public class CoinCounter : MonoBehaviour
{
    private int coins = 0;

    public void AddCoin()
    {
        coins++;
        Debug.Log("Всего монет: " + coins);
    }
}
```

3. Выберите корневой объект игрока (`character-digger`).
4. Добавьте ему компонент **CoinCounter** через **Add Component**.

**Объяснение кода:**

- `private int coins = 0` — количество собранных монет. В начале игры равно нулю.
- `public void AddCoin()` — метод, который сможет вызывать другая программа.
- `coins++` увеличивает количество на 1.

**Проверка:** компонент `CoinCounter` присутствует на объекте игрока. Пока число монет ниоткуда не увеличивается — это следующий этап.

## Этап 4. Изменяем Coin.cs: монета увеличивает счётчик

**Задача:** при подборе монеты найти `CoinCounter` у игрока, увеличить счётчик и только потом удалить монетку.

Полностью замените код `Coin.cs` на **вторую версию**:

```csharp
using UnityEngine;

public class Coin : MonoBehaviour
{
    private void OnTriggerEnter(Collider other)
    {
        if (!other.CompareTag("Player"))
            return;

        CoinCounter counter = other.GetComponent<CoinCounter>();

        if (counter == null)
            return;

        counter.AddCoin();
        Destroy(gameObject);
    }
}
```

**Объяснение кода:**

- `!other.CompareTag("Player")` означает «если это **не** игрок».
- `return` прекращает работу метода, когда взаимодействие не подходит.
- `GetComponent<CoinCounter>()` ищет компонент счётчика у объекта, вошедшего в триггер.
- `counter == null` — проверка, что компонент действительно найден.
- `counter.AddCoin()` увеличивает счётчик.

### Проверяем

1. Создайте 3–5 монет (можно сделать дубликаты через **Ctrl + D**).
2. Поставьте их в разных местах рядом с игроком.
3. Запустите сцену и соберите все монеты.
4. Следите за **Console**.

Ожидаемые сообщения:

```text
Всего монет: 1
Всего монет: 2
Всего монет: 3
```

**Важно:** все монеты используют один счётчик, потому что `CoinCounter` находится на игроке.

## Этап 5. Создаём текстовый показатель монет на экране

**Задача:** вывести число собранных монет в угол экрана, как мы ранее вывели здоровье игрока.

### Шаги в Unity

1. В **Hierarchy** найдите ранее созданный **Canvas** с объектом `HealthText`.
2. Нажмите правой кнопкой на **Canvas → UI → Text - TextMeshPro**.
3. Назовите новый объект **CoinText**.
4. В компоненте **TextMeshPro - Text (UI)** найдите поле **Text Input**.
5. Напишите: `Монеты: 0`.
6. Установите читаемый размер шрифта, например `32`.
7. В `Rect Transform` выберите привязку **Top Left** и разместите надпись ниже `HealthText` (например, `Pos X = 155`, `Pos Y = -90`, `Width = 300`, `Height = 50`; координаты при необходимости подстроить под Canvas).
8. В `Canvas` проверьте: `Render Mode = Screen Space - Overlay`. Для разных разрешений удобно `Canvas Scaler → Scale With Screen Size`.

Пример структуры **Hierarchy**:

```text
Canvas
├── HealthText
└── CoinText

character-digger
├── CharacterController
├── PlayerController
├── PlayerHealth
├── PlayerEnemyCollision
└── CoinCounter
```

*Примечание:* компоненты игрока перечислены условно: в Unity они отображаются в Inspector, а не как дочерние объекты Hierarchy.

**Проверка:** в игровом окне видно `Монеты: 0` и существующую надпись здоровья. Пока число не обновляется — добавим обновление.

## Этап 6. Финальная версия CoinCounter.cs: обновляем UI

**Задача:** после каждого сбора монеты менять текст без ручного редактирования.

Полностью замените код `CoinCounter.cs`:

```csharp
using UnityEngine;
using TMPro;

public class CoinCounter : MonoBehaviour
{
    private int coins = 0;

    public TMP_Text coinText;

    private void Start()
    {
        UpdateCoinText();
    }

    public void AddCoin()
    {
        coins++;
        UpdateCoinText();

        Debug.Log("Всего монет: " + coins);
    }

    private void UpdateCoinText()
    {
        if (coinText != null)
        {
            coinText.text = "Монеты: " + coins;
        }
    }
}
```

### Подключаем текст в Inspector

1. Выделите **игрока** (`character-digger`).
2. В компоненте **Coin Counter (Script)** появится поле **Coin Text**.
3. Перетащите объект **CoinText** из Hierarchy в поле **Coin Text**.
4. Убедитесь, что в Console нет красных ошибок компиляции.
5. Запустите игру и соберите монеты.

**Результат:**

```text
Health: 100 / 100
Монеты: 0
```

После сбора трёх монет:

```text
Health: 100 / 100
Монеты: 3
```

**Объяснение кода:**

- `using TMPro;` подключает работу с текстом TextMeshPro.
- `TMP_Text coinText` — ссылка на объект интерфейса, которую назначаем в Inspector.
- `Start()` устанавливает начальное значение надписи.
- `UpdateCoinText()` вызывается **только когда надо изменить число**, а не каждый кадр.
- Проверка `coinText != null` предотвращает ошибку при незаполненном поле Inspector.

### Итоговый Coin.cs

## Этап 7. Итоговое тестирование

Проверьте по очереди:

- [ ] При старте игры отображается `Монеты: 0`.
- [ ] Первая монета исчезает при касании игрока.
- [ ] Надпись становится `Монеты: 1`.
- [ ] После нескольких монет число увеличивается до 2, 3, 4 и т. д.
- [ ] Если монету касается враг, количество монет игрока не увеличивается.
- [ ] Сбор сердечка по-прежнему лечит игрока и не увеличивает счётчик монет.
- [ ] Камера и движение игрока работают как раньше.

### Частые ошибки

| Ошибка | Причина | Как исправить |
|---|---|---|
| Монетка не исчезает | `Is Trigger` выключен или коллайдер не пересекается с игроком | Включить `Is Trigger`, проверить размеры коллайдера |
| `Монеты: 0` не меняется | Не назначен `CoinText` в поле `Coin Text` | Перетащить `CoinText` в Inspector игрока |
| Монета исчезает, но счётчик не растёт | На игроке нет `CoinCounter` либо используется старый скрипт `Coin.cs` | Добавить `CoinCounter` на тот же объект, что `CharacterController`, и обновить `Coin.cs` |
| Монета не срабатывает | У игрока нет тега `Player` | Выбрать корневой объект игрока и установить `Tag = Player` |
| Красная ошибка в скриптах | Имя файла и класса отличаются либо синтаксическая ошибка | Проверить `Coin.cs` ↔ `class Coin`, `CoinCounter.cs` ↔ `class CoinCounter` |
| Текст находится за пределами экрана | Неправильно выставлены якоря и позиция UI | Поставить Anchor `Top Left` и поправить `Pos X`, `Pos Y` |

> Если триггер не срабатывает, сначала проверьте Player Tag, `CharacterController` и настройки коллайдера. При необходимости на монетку можно добавить **Rigidbody** с `Is Kinematic = true`, `Use Gravity = false`. Не добавляйте Rigidbody игроку: он уже двигается через `CharacterController`.

## Самостоятельная работа студентов

**Задание 1. Монетный маршрут.** Разместите не менее 10 монет на разных платформах. Игрок должен собрать все монеты, используя движение и прыжки.

**Задание 2. Монеты разной стоимости.** Измените `Coin.cs`, чтобы золотая монета приносила 5 очков, а обычная — 1. Подсказка: добавить поле `public int value = 1;`, а метод `AddCoin()` изменить на `AddCoins(int amount)`.

**Задание 3. Победа при сборе монет.** Когда игрок накопит 10 монет, выведите в Console сообщение `Все монеты собраны!`. Подсказка: проверка `if (coins >= 10)` после увеличения счётчика.

**Задание 4. Дизайн интерфейса.** Расположите рядом две надписи: `Health: 100 / 100` и `Монеты: 0`. Подберите читаемые цвета и размер шрифта. Проверьте вид в окне **Game**.
