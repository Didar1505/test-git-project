# Unity — урок №4. Знакомство с 3D-средой и создание уровня

> **Адаптированная методичка для учащихся.** Основа — предоставленный материал «Урок №4. Знакомство с 3D-средой». Сохранены создание проекта Universal 3D, импорт ассетов, сборка карты, коллайдеры и знакомство с камерой. Исправлена подготовка камеры: она не должна появляться внутри персонажа или земли.

**Рекомендуемое время:** 80–90 минут (ориентир преподавателю, не требование исходного материала).  
**Результат:** сцена с островами/платформами и декорациями, физические коллайдеры, один объект Main Camera со скриптом `CameraFollow`. Персонаж может быть добавлен в сцену, а движение будет реализовано на уроке №5.

## 1. С чего начинаем

3D-игра использует три оси: **X** — вправо/влево, **Y** — вверх/вниз, **Z** — вперёд/назад. В 2D мы обычно использовали X и Y. В Unity координата Y — вертикальная.

**Вопрос классу:** как герой должен переходить с одного острова на другой? Что произойдёт без коллайдера на поверхности острова?

## 2. Создаём проект

1. Откройте **Unity Hub → New project**.
2. Выберите шаблон **Universal 3D** (URP), укажите имя проекта, нажмите **Create project**.
3. Сохраните сцену командой **File → Save As**: `Assets/Scenes/Level01.unity`.
4. В `Assets` создайте папки `Scenes`, `Scripts`, `Map`, `Characters`, `Materials` (можно также `Models`).

Данные папки — пример удобной структуры. Если импортированные ассеты уже создали собственные папки `Map`/`Characters`, перемещать их необязательно.

### Инструменты Scene

- **Q** — рука, перемещение вида;
- **W** — перемещение выбранного объекта;
- **E** — вращение;
- **R** — масштабирование;
- **F** — фокус на выделенном объекте.

В окне **Scene** мы строим уровень; в окне **Game** видим то, что снимает камера игры.

## 3. Собираем платформы и острова

Материал урока предлагает тайлы из ассетов **Kenney**. Можно использовать тот же комплект моделей, что был выдан группе, либо доступные в проекте тайлы. Каталог автора: https://kenney.nl/assets

1. Откройте папку `Map` в Project.
2. Перетащите один тайл с травой в **Scene** и задайте, например, координаты `(0, 0, 0)`.
3. Продублируйте плитку сочетанием **Ctrl + D**; перемещайте дубликаты по X и Z так, чтобы верхние поверхности соединялись без больших щелей.
4. Добавьте несколько отдельных островков для будущих прыжков. Оставьте первую площадку большой и безопасной.
5. Добавьте деревья, цветы, камни, заборы как декоративные объекты.
6. Переименовывайте объекты в Hierarchy по смыслу: `Ground_Start`, `Platform_02`, `Tree_01`.

**Важно:** не угадывайте расстояние между платформами. Размер тайла зависит от конкретного ассета. Сначала попробуйте перемещение персонажа на уроке №5, затем подстройте зазоры.

### Коллайдеры

Без коллайдера видимая земля может не останавливать персонажа.

- Выделите каждую игровую площадку.
- В Inspector найдите `Box Collider` или `Mesh Collider`. Если коллайдера нет, нажмите **Add Component → Box Collider**.
- Проверьте, что **Is Trigger** выключен.
- Убедитесь, что зелёная верхняя грань совпадает с верхней гранью коллайдера. При необходимости настройте `Center` и `Size`.
- Для сложной формы иногда нужен `Mesh Collider`, но на простых блоках предпочтителен `Box Collider`.

**Самопроверка:** нажмите на платформу. В окне Scene должен быть виден контур коллайдера вокруг твёрдой части острова.

## 4. Подготовим Main Camera

В новой сцене **Main Camera уже существует**. Не добавляйте вторую, если в Hierarchy виден объект `Main Camera`: иначе могут появиться лишние камеры и аудиослушатели.

Откройте `Assets/Scripts`, создайте **MonoBehaviour Script** с именем `CameraFollow` (файл **`CameraFollow.cs`**).

**Почему нельзя назвать скрипт `Camera.cs`?** В Unity уже есть компонент `UnityEngine.Camera`; совпадение имён легко приводит к путанице в коде.

### Полный код CameraFollow.cs — версия для урока №4

```csharp
using UnityEngine;

public class CameraFollow : MonoBehaviour
{
    [Header("Target")]
    public Transform target;

    [Header("Camera Settings")]
    public float distance = 4.5f;
    public float height = 3f;
    public float smoothSpeed = 10f;
    public float lookHeight = 1.5f;

    void Start()
    {
        if (target == null) return;
        MoveCamera(true);
    }

    void LateUpdate()
    {
        if (target == null) return;
        MoveCamera(false);
    }

    void MoveCamera(bool instant)
    {
        Vector3 desiredPosition = target.position
            + Vector3.up * height
            - Vector3.forward * distance;

        float t = instant ? 1f :
            1f - Mathf.Exp(-smoothSpeed * Time.deltaTime);

        transform.position = Vector3.Lerp(
            transform.position,
            desiredPosition,
            t
        );

        transform.LookAt(target.position + Vector3.up * lookHeight);
    }
}
```

### Разбираем код по частям

- `public Transform target` — объект, за которым нужно следовать. После урока №5 сюда поместим персонажа.
- `distance = 4.5f` — расстояние позади персонажа по мировой оси Z (пока камера **не** вращается мышью).
- `height = 3f` — насколько камера выше точки персонажа.
- `lookHeight = 1.5f` — на какую высоту тела героя направлен взгляд камеры.
- `Start()` — один раз устанавливает камеру в нужное положение, чтобы при старте не было заметного перемещения из случайной точки.
- `LateUpdate()` — двигает камеру после обычного `Update`, в котором позже будет перемещаться игрок.
- `Vector3.Lerp` — плавно приближает текущую позицию камеры к нужной. Выражение `1 - Mathf.Exp(-smoothSpeed * Time.deltaTime)` делает сглаживание устойчивее при разных FPS.
- `transform.LookAt(...)` — разворачивает камеру к верхней части героя.

Этот скрипт **специально простой**: он следит за персонажем из фиксированного направления. На уроке №6 мы заменим его на понравившуюся нам камеру с вращением мышью.

### Как прикрепить скрипт

1. Выделите **Main Camera** в Hierarchy.
2. Нажмите **Add Component → CameraFollow**.
3. Убедитесь, что на Main Camera **один** пользовательский скрипт управления камерой.
4. Пока поле `Target` может оставаться пустым: герой ещё не настроен. В этом случае скрипт ничего не делает и не выдаёт ошибку.

Настройки первой версии:

| Поле | Значение |
|---|---:|
| Distance | 4.5 |
| Height | 3 |
| Smooth Speed | 10 |
| Look Height | 1.5 |

## 5. Самостоятельная работа

1. Создайте стартовый остров, на котором хватит места, чтобы разбежаться и прыгнуть.
2. Создайте не менее двух следующих платформ и украсьте сцену тремя типами объектов.
3. Проверьте коллайдеры на всех платформах, на которые должен наступать герой.
4. Подготовьте в Hierarchy **одну** Main Camera и скрипт `CameraFollow`.
5. *Дополнительно:* сделайте отдельный остров для «льда» — пригодится на уроке №6.
